The MANTI. platform

An open-source handheld NDVI device for collecting measurements on plant health.

Purpose

Built for validation and experimentation.

This repository contains a fully open hardware and software implementation of a handheld NDVI measurement device.

System model

From sensing to output.

Red and near-infrared spectral capture, on-device NDVI logic, and structured measurement output for downstream analysis.

Repository structure

Core project assets are grouped into four practical layers.

Firmware

ESP32 code, NDVI calculation logic, sensor setup, and data output.

Hardware

Schematic, PCB design, manufacturing files, BOM, and carrier architecture.

Mechanical

3D-printable enclosure files and assembly notes.

Documentation

Assembly guidance, wiring, NDVI theory, and troubleshooting notes.
